The API client for people and agents

Connect OpenAPI, MCP, or gRPC. Explore APIs yourself, or let an agent write and run typed scripts. Every request stays visible and inspectable.

Download on the Mac App Store Try Live Demo

Connect your API

OpenAPI from a URL or a file, MCP servers, and gRPC or Twirp through server reflection or your .proto files. Sign in with your browser instead of pasting a token.

Run it yourself or ask an agent

Click a method and Kaja drafts the call as a TypeScript script, with autocomplete for every field. Or point Claude Code, Codex, Cursor or any other MCP-capable agent at Kaja.

See exactly what happened

Every request, response, header, status and duration stays visible, whether you made the call or an agent did.

Your files, your secrets

A workspace is a folder: one kaja.json and your scripts, ready to commit next to your code. Tokens stay in the macOS Keychain, never in the file.
